## What I'm building

- [**Rozenite**](https://github.com/callstackincubator/rozenite) - A React Native DevTools plugin framework that also brings the experience to the web and to agents.
- [**Voltra**](https://github.com/callstackincubator/voltra) - Build Live Activities and widgets for iOS and Android with server-side rendering, updates, and React Native-first ergonomics.
- [**Harness**](https://github.com/callstackincubator/react-native-harness) - My go-to tool for testing native modules without mocks, but with the developer experience of writing tests in Jest.
- [**React Native Grab**](https://github.com/callstackincubator/react-native-grab) - Select a UI element and copy its context to an agent, enabling surgical changes without wasting tokens on exploration.
